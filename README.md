# Simulador de Gestor de Procesos para Sistemas Operativos

## Breve Descripción

Este proyecto es un simulador básico de un gestor de procesos desarrollado en Python. Emula la administración de múltiples procesos, la asignación de memoria y utiliza el algoritmo de planificación Round Robin con un menú interactivo para la gestión de procesos.
